# 💬 Chat Application

A beautiful, real-time chat application built with React and TypeScript. Designed by Pester Mbhetse (Pestingo).

## 🚀 Live Demo

Visit the live application: [Chat Application](https://effortless-truffle-e08e67.netlify.app)

## ✨ Features

- 🎨 Beautiful, modern UI with Tailwind CSS
- 💬 Real-time messaging
- 👤 User authentication
- 🚀 Fast and responsive
- 📱 Mobile-friendly design
- 🔒 Secure data handling
- ⚡ Optimized performance
- 🌙 Clean, intuitive interface

## 🛠️ Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/Pestingo/Full-Stack-Chat-Application.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 🔧 Tech Stack

- ⚛️ React 18 - Modern UI development
- 🎨 Tailwind CSS - Utility-first styling
- 📦 Vite - Next generation frontend tooling
- 🔷 TypeScript - Type-safe code

- 🔔 React Hot Toast - Beautiful notifications
- 📅 Date-fns - Modern date utility
- 🎨 Lucide React - Beautiful, consistent icons

## 📁 Project Structure

```
src/
├── components/        # React components
│   ├── Chat.tsx      # Main chat interface
│   └── Login.tsx     # Authentication form
├── lib/              # Utilities and services
│   ├── api.ts        # API functions
│   └── storage.ts    # Data storage logic
├── store/            # State management
│   ├── authStore.ts  # Authentication state
│   └── messageStore.ts # Messages state
└── App.tsx           # Root component
```

## 🚀 Deployment

1. Build the application:
   ```bash
   npm run build
   ```

2. The build output will be in the `dist` directory.

3. Deploy using Netlify:
   - Connect your GitHub repository
   - Configure build settings:
     - Build command: `npm run build`
     - Publish directory: `dist`
